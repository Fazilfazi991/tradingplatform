# Live intelligence runtime

Batch 11 permits internal collection and interpretation, not prediction research. External text enters an `UNTRUSTED_DATA_NO_INSTRUCTIONS_NO_TOOLS` envelope. Tier 0 work is deterministic; Tier 1 is routine classification; Tier 2 is complex interpretation; Tier 3 may request a bounded second-model review. Invalid structure, unsupported references, invented entities or numbers are rejected or quarantined.

Routing is configured at runtime. OpenAI is the default first choice only when present; configured DeepSeek, Qwen, GLM and Moonshot providers may follow. Provider changes are recorded. Budget exhaustion, total provider failure or insufficient evidence returns `UNKNOWN`/`ABSTAIN` without interrupting ingestion.

Every internal snapshot declares `ALL_FIXTURE`, `PARTIAL_LIVE` or `ALL_LIVE`. A partial-live snapshot is labelled **PARTIAL LIVE INTELLIGENCE — NOT A LIVE MARKET PREDICTION** and cannot silently acquire fixture orientations.

## Current engine boundary

- News/Event: RBI and SEBI official RSS metadata can be live internally.
- Macro: genuine RBI observations only; absent numeric inputs stay unknown.
- Psychology: may derive limited attention/tone from legitimate events; no social-data substitute.
- Fundamental and Flow/Derivatives: insufficient until approved sources exist.
- Technical and Historical: engineering-only while Upstox/history activation is deferred.
