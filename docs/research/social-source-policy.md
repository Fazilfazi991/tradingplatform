# Social and Attention Source Policy

No social or search-attention source is active. Unofficial scraping of X/Twitter, Telegram, Discord,
Instagram, Facebook, private groups, or other circumvention is prohibited.

Candidates are Google Trends API Alpha, Reddit Data API, and YouTube Data API. Google Trends still needs
access and product-rights review; unofficial libraries do not create commercial rights. Reddit requires
explicit approval and a separate commercial agreement, plus retention, privacy and deletion controls.
YouTube requires API-policy, retention and display review. All remain adapters/contracts only.

Candidate approval must document API basis, commercial rights, rate limits, retention, attribution,
privacy, deleted-content handling, redistribution and incident shutdown procedures.
