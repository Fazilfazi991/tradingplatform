# Evidence Fusion Operations

1. Require a common scope, horizon, cutoff and fusion policy version.
2. Verify each upstream snapshot exists and was causally available by cutoff.
3. Build dependency graph from source, event, cluster and feature provenance.
4. Seal deterministic contributions, contradictions, agreement, uncertainty and abstention.
5. Replay the same packet and compare semantic state/hash during incident recovery.
6. Audit availability, staleness, conflicts, dominance, dependency penalties and abstention.

The structured output is authoritative. An optional provider-neutral LLM may translate the explanation,
but cannot change fusion state, quality, agreement, uncertainty or abstention.
