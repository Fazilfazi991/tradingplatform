# Psychology Evidence Methodology

Aggregation is cluster-first and weights novelty, relevance, source reliability, confirmation and
strength. It is not positive-article count divided by total articles. Disagreement is weighted dispersion
between independent cluster orientations and reduces certainty.

Fear requires multiple inputs such as negative breadth, uncertainty and attention. Euphoria similarly
uses positive breadth, attention and acceleration. Crowding uses narrative dominance; speculation uses
rumour burden, attention and acceleration. With fewer than two independent clusters, these states are
`UNKNOWN` and the evidence engine returns `INSUFFICIENT_PSYCHOLOGY_EVIDENCE`.

Decay metadata distinguishes fast rumours, slower material events and longer policy narratives, but no
decay constant or threshold is optimized against returns. The evidence score remains null and is not a
price probability, expected return, recommendation or alpha claim.
