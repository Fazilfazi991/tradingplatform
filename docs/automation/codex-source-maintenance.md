# Codex source maintenance

The maintenance report lists failing/stale sources, schema anomalies, unresolved entities, volume
changes, candidates, collector/parser versions, impacted tests, and recommended investigation.

Codex may inspect evidence, propose a patch, implement it on a controlled branch, and run tests. Report
generation makes no production change. Codex may not activate sources, reset compliance gates, publish
intelligence/predictions, or change model behavior.
