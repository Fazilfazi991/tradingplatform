# Target catalog V1

Targets are evaluation/training outcomes and never feature inputs. The default decision boundary is
after session close; the current engineering convention measures close-to-future-close outcomes.

| Family | Definitions |
|---|---|
| Forward return | 1, 3, 5, and 10-session close returns |
| Direction | Up, down, or neutral with a configurable symmetric neutral band |
| Barrier | Configurable upper/lower barrier, horizon, and conservative lower-first same-bar collision |
| Volatility | Dispersion of future path returns over each horizon |
| Excursion | Maximum favorable and adverse high/low excursion over 1/3/5/10 sessions |

Economic thresholds remain experiment configuration, not universal product truth.
