# DR-021: Prediction Engine V1

Status: accepted for internal exploratory research.

Prediction Engine V1 uses causally reconstructed real-market features and historical outcomes. It is exploratory real-market forecasting research, not a public prediction service.

The historical universe is survivorship-biased because point-in-time NIFTY 200 membership is unavailable. V1 therefore cannot establish formal historical NIFTY 200 predictive performance. Price-adjustment semantics also remain unverified, so structural-action windows are excluded conservatively.

A holdout pass is not verification. Forward paper validation is mandatory before any verified state. No live customer prediction may be published during V1 research, and LLMs may explain reports but cannot generate model probabilities.
