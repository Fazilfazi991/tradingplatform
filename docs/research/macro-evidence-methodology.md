# Macro evidence methodology

Macro state is multi-axis: growth, inflation, policy, liquidity, global risk and commodity pressure.
Contradictions such as accelerating growth with tightening liquidity remain visible rather than
being forced into one bullish/bearish label.

Surprise requires a consensus observation available strictly before release. The originally
released value is compared with that expectation; revisions never rewrite historical surprise.
Late collection uses the actual system observation time.

`MacroEvidenceEngine` returns structured states, sector exposures, contradictions, certainty,
quality and provenance. Directional evidence remains unset in V0 and is not stock probability,
expected return or a recommendation.
