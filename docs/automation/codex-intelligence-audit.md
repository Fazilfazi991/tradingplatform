# Codex intelligence audit

A future daily audit receives source health, ingestion failures, entity issues, universe changes, and
intelligence anomalies. It may create a report or issue, propose a controlled patch, implement that
patch on a branch, and run tests.

Research ideas are hypothesis proposals containing economic rationale, required data, availability,
target, leakage risk, multiple-testing family, estimated sample, horizon, and recommendation. They do
not become features automatically. Publishing predictions, activating unapproved sources, changing
thresholds, and modifying research/compliance gates are prohibited.
