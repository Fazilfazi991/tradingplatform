# DR-018 — Live intelligence activation

Status: Accepted

## Decision

Real intelligence collection and grounded LLM interpretation may operate internally before real market-prediction research is authorized. Live intelligence does not authorize live return predictions.

The runtime must enforce untrusted-source envelopes, strict structured output, evidence-reference containment, configurable provider routing, visible failover, semantic caching, operational budgets, hallucination quarantine and explicit live/fixture provenance. Missing evidence produces `UNKNOWN`, `INSUFFICIENT_EVIDENCE` or `ABSTAIN`.

The Fusion UI is frozen. Prediction Engine V1, Upstox, PostgreSQL requirements, public predictions, trading actions and source-policy bypass are outside this decision.
