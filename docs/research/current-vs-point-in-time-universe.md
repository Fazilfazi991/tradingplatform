# Current versus point-in-time universe

The 200-name snapshot is `CURRENT_UNIVERSE_SNAPSHOT`. It supports current technical state,
same-security historical analogues, engineering validation, and current-universe research.

It is not historical membership. `POINT_IN_TIME_UNIVERSE_UNAVAILABLE` remains active. Using these
names cross-sectionally over history is `SURVIVORSHIP_BIASED_CURRENT_UNIVERSE` and cannot establish
unbiased NIFTY 200 performance, historical constituent selection, or market-wide predictive edge.
