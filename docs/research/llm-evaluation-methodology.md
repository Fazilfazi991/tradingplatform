# LLM evaluation methodology

Compare only configured providers on the same versioned evidence envelopes and schemas. Report schema success, task correctness, correct abstention, unsupported-claim rate, grounding rate, latency and estimated cost separately. Do not choose a provider from one aggregate score.

Tier 1 fixtures test event class, tone, summary and tags. Tier 2 fixtures test policy, filing and multi-entity interpretation. Tier 3 tests high-materiality ambiguity and optional second-model disagreement. Every invented entity, number, event, source reference or unsupported causal claim becomes a quarantined incident and regression fixture.

Real observations measure operational behavior, not return prediction quality. No stock-return evaluation is authorized.
