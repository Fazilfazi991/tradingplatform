# Macro taxonomy

Categories cover monetary policy, rates, liquidity, inflation, GDP, PMI, IIP, employment, fiscal,
currency, bond yields, credit, money supply, trade/current account, commodities, volatility, global
equities/rates and geopolitics.

RBI events distinguish repo, SDF, MSF, CRR, liquidity operations, OMO, forex, banking regulation,
payments, credit, inflation/growth commentary and financial stability. Missing numeric evidence does
not create a numeric observation.

Units retain raw value/unit and allow only explicit normalization for percent, basis points, index
levels, USD, INR, million and billion. Ambiguous units fail validation.
